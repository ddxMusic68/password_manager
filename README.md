# snakeWebsite
## description
Tkinter GUI using Fernet to encrypt/decrypt passwords using a json file to store data

## versions
```
cffi>=2.0.0,<3.0
cryptography>=46.0.3,<47.0
pycparser>=2.23,<3.0
tk>=0.1.0<1.0
```
## installation
```
git clone https://github.com/ddxMusic68/snakeWebsite
cd project
pip install -r requirements.txt
python -u ./password_manager.py
```
## structure
```
src
|---enctrypted_password.json    -stores applications and enctrypted passwords
|---password_manager.py    -main py logic
|---requirements.txt    -info about dependencies versions
```
